Kufu Labs

Kufu (工夫, *kufū*) is Japanese for devising better ways to do something: practical ingenuity. Dictionary source.

An open-source lab for building and testing small tools around reported research-workflow problems. Each exploration connects an original problem report to an intended user, an implementation and evidence of what has actually improved.

Explore and run

Open Home, Explorations, Problems, Sources or Validation. Each tab is an independent page; the interactive pose demo can open in a separate browser tab. Exploration entries describe the runtime, constructed inputs, launch command, expected result and verification limits.

Run npm ci --ignore-scripts --no-audit --no-fund, then npm run build and npm test. Serve the reviewed package with python3 -m http.server 8879 --bind 127.0.0.1 --directory dist. See delivery for pinned scientific checks, the protected Vercel pipeline and retained evidence; WORKSPACE.md records actual publication/deployment state.

Structure and boundaries

research/ preserves sourced investigations and decisions. projects/<name>/ keeps each contribution, executable check, source pin and limits. site/catalog.json is the maintained hub catalogue; site/build.py generates the root website and safe, readable copies of the Markdown research records. Keep upstream implementation checkouts separate.

The deletion diagnostic records an unfixed repeated-export provenance defect. The coordinate-filtering result and this remaining defect are kept separate. Source revisions, patches, commands and outcomes live with each project.

No recordings, model weights, environments, patient information or credentials belong in the repository. Dataset, model and software licences are independent. A passing check does not establish scientific correctness, adoption, clinical utility or researcher benefit.
