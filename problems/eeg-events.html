Preserve an unchanged EEG annotation onset

An annotation marks a point or interval in a time series. At some sampling rates, attaching it to a recording rounds its onset even though it lies inside the allowed interval. A floor-based lookup can then select the preceding sample.

Bounded interior-onset candidate passes locally

Who encounters it and why it matters

EEG/MEG researchers using sample-aligned annotations in MNE-Python.

Avoid changing an already valid interior timestamp during a crop/attachment operation. Correct software indexing does not validate an acquisition clock or biological result.

Science and terms

At 512 samples per second, sample 1 is at 0.001953125 seconds. Datetime rounds that to 0.001953 seconds. The 125-nanosecond change crosses a floor-index boundary; it does not show that a physical recording clock drifted by a whole sample. All tested signals are constructed zeros, not recordings or a neural model.

Sampling rate
How many samples represent each second; 512 Hz means 512 samples per second.
Annotation onset
The time at which a marked event or interval begins.
Floor versus rounded lookup
Floor chooses the lower integer sample index; nearest rounding already finds the intended sample in this tested baseline case.

Where the problem appears

  1. Create a constructed time series

    One zero-valued EEG channel lasting four seconds.

  2. Mark sample 1

    Use the exact generated time as an annotation onset.

  3. Attach or crop

    Run the real MNE methods, without reading recordings.

  4. Compare values and indexes

    Inspect the saved float, default floor lookup and existing rounded lookup.

Evidence and existing tools

MNE 1.13.2 and current source 0265fc9 reproduce the sample-1 shift at 300, 512 and 2048 Hz. Existing use_rounding=True correctly locates the tested sample on both revisions.

  • MNE precision report #12327
  • Existing lookup rounding option
  • Separate origin/first-sample report #13890

The solution being tested

The local candidate keeps the original onset only if neither boundary was clipped and the original span fits inside the datetime-resolved limits. The existing clipping path remains. It addresses this unnecessary mutation, not the full timing-precision problem.

Existing Annotations.crop and Raw.set_annotations path; no application, plugin or new API.

Validation and limits

The extended existing crop test covers four rates and dated/undated origins. Six baseline cases fail; all 12 selected candidate checks pass, including four other existing crop tests. Applicable upstream pre-commit checks pass.

What remains unverified

This bounded candidate does not repair all datetime precision, clipping, first-sample/origin, serialization or hardware-clock issues. No real recordings, user benefit or upstream acceptance. Pinned scientific checks passed in PR #25 CI. MNE requires personal human review before an upstream submission.

What would count as resolving it

Unchanged interior onsets retain their original value while existing crop limits and regression checks remain valid. Broader timing and research usefulness need separate evidence.

Next step

Review the bounded mechanism and source policy; recheck upstream before further investment. No fully automated MNE submission or outreach.
