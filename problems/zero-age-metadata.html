Preserve a supplied age of zero

A dataset supplies an age value of zero. During metadata processing, software treats zero as false and leaves the exported age empty. A known value has become indistinguishable from a missing annotation.

Constructed metadata workflow preservation demonstrated; researcher benefit unvalidated

Who encounters it and why it matters

Researchers reusing biological sample metadata exported by refine.bio.

Preserve a supplied zero instead of turning it into a missing value. Affected public samples, prevalence and researcher benefit remain unmeasured.

Science and terms

Sample metadata describes the biological material being analysed. Researchers use those annotations when selecting or comparing samples. A numeric zero and an absent value have different meanings; this software check preserves what was supplied without interpreting the biology.

Harmonisation
Turning supplied annotations into consistent fields and representations.
Truthiness check
A programming condition that treats numeric zero as false, alongside values such as an empty string.
TSV / JSON
Text file formats used here for actual metadata exports.

The solution being tested

The patch preserves zero in refine.bio’s harmoniser and model metadata output while retaining existing handling of empty or unknown values. The tested path creates real sample records and writes actual TSV/JSON metadata files. It does not infer missing ages or change their units.

Validation and limits

The real SRA creation and worker metadata path passed in Linux CI with 91 migrations per revision. Both zero cases change from empty to 0.000 in ALL, EXPERIMENT and SPECIES TSV output; positive/empty/unknown controls stay unchanged. Five existing export regressions pass per revision.

What remains unverified

No live source ingestion, expression processing, dispatch/upload, cloud deletion, populated-database upgrades, full upstream suite, affected public-sample audit, acceptance or researcher benefit.

What would count as resolving it

An explicit zero annotation survives supported ingestion, harmonisation and export without changing missing-value handling; workflow relevance independently assessed.
