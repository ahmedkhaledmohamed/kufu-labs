Implementation, provenance & limits

The page reads a frozen oracle table generated with the actual sleap-nn tensor FilterPipeline. It does not reimplement numerical metrics or NMS in JavaScript. All other filters are disabled. OKS uses the candidate’s bounding-box area and κ = 0.1; only shared visible nodes contribute. No shared nodes or a zero-area candidate produce OKS = 0.

The generator bypasses eager package initializers to avoid loading prediction/model dependencies; the actual FilterPipeline, Outputs and PreprocInfo modules run unchanged, on CPU. These results cover only the frozen synthetic examples and selected revision. SLEAP’s legacy NumPy path can use a different OKS argument order. This standalone demo is not integrated into SLEAP, does not edit labels, and has not been validated with researchers.
